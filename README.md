# sql_analysis_agent

Агент для аналитики по таблицам: вопрос на естественном языке → SQL → выполнение →
самоисправление по ответам базы → ответ с таблицей. Построен на LangGraph, работает
локально через Ollama.

> **Данные синтетические.** БД сгенерирована скриптом `sqlagent/db/generate.py`
> (Faker + random, seed=42), реальных данных банка в проекте нет.

## Данные

SQLite, 7 таблиц в двух доменах:

- **Инкассация:** `branches`, `atms`, `routes`, `collections`
- **Закупки:** `suppliers`, `contracts`, `invoices`

Схема с комментариями описана в [`sqlagent/db/schema.sql`](sqlagent/db/schema.sql).
SQLite хранит эти комментарии в `sqlite_master`, поэтому агент видит их вместе со схемой.

В данные специально заложены аномалии, список генератор пишет в `data/anomalies.json`:

| Аномалия | Как выглядит |
|---|---|
| Недостачи на маршруте | Один маршрут с июня систематически сдаёт меньше, чем показывают счётчики банкоматов |
| Дробление закупки | 7 договоров чуть ниже порога закупки без конкурса, поставщик зарегистрирован за 2 недели до первого |
| Дубли счетов | Тот же номер и сумма по тому же договору, оплачены дважды |
| Грязные значения | `г. Москва` / `москва` / `Москва`; NULL в суммах отменённых выездов |

## Запуск

```bash
uv sync
uv run python -m sqlagent.db.generate   # → data/bank.db, data/anomalies.json
```
